# Blockfall

A slick, mobile-first falling-blocks game in a single HTML file. No build step, no dependencies.

Open `index.html` (or the deployed URL) in Safari on iPhone, then Share → Add to Home Screen for a full-screen app.

**Controls**
- Swipe left/right: move · Drag down: soft drop · Flick down: hard drop
- Tap right side: rotate CW · Tap left edge: rotate CCW · Hold button: hold piece
- Keyboard: arrows, Z/X rotate, Space hard drop, C hold, P pause
